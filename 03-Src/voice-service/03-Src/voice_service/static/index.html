如何配置云端

在项目目录双击“配置云端语音.cmd”，在本机窗口输入北京地域的百炼 API Key，随后刷新本页。密钥不需要发到聊天里，也不经过本网页。配置完成后仍需选择云端并勾选对应上传权限。关闭权限会取消该类正在执行的云端请求。

云端会产生服务商用量；每会话最多 60 次请求，不自动重试。当前先比较完整 WAV 延迟，尚未提供流式首段播报。
