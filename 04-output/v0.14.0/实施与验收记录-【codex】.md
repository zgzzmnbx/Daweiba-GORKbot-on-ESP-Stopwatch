# v0.14.0-dev 造价助手实施与验收

日期：2026-09-26。范围：电脑端源码；固件保持 v0.9.0-dev。正式实例未重启，未推送远端。

## 已实现

- PRD 22 与版本计划：Gork 提供交互入口，造价智算提供业务能力，既有语音服务和 BLE 不合并进业务适配器。
- `companion/cost.py` 固定本机接口适配：服务身份校验、分页项目列表、项目与任务详情、classic 知识检索和显式授权问答。仅白名单字段返回，错误不暴露上游响应体；非预期结构报错，不伪装成无结果。
- Gork 新增造价助手标签页，沿用现有浅色双栏和左侧常驻动画。回答、出处、标题路径、证据状态及预设演示标识分开显示。
- 工作台所有权独立于语音会话；知识查询与现有 generation/全局停止联动。前端所有业务查询有过期结果保护；模型许可单次消费，不保存默认勾选。
- 项目必须从分页列表明确选择，状态和任务显示为中文条目，不把项目 ID 当知识 project_key。知识查询首版为通用知识查询，不注入项目私有上下文。
- 对话语音转写可带入问题；人工编辑并确认的摘要可送回对话，复用既有电脑/桌面/Watch 输出。此动作本身不朗读、不发送，不调用通用 AI 二次改写。

## 使用与下一步

1. 启动真实造价智算服务；默认期望本机 8000 端口。若端口不同，在 Gork 本机忽略配置中设置 `cost_url = "http://127.0.0.1:实际端口"`。只允许本机 HTTP，不自动启动业务服务。
2. 重开升级后的 Gork 进程（本次未执行），进入“造价助手 → 检查连接”。静态页面刷新不等于后端已经升级。
3. 输入问题 → 查询依据。需要模型整理时单次勾选授权，留意可能发送问题和依据、产生模型费用；没有授权不会调用 ask。
4. 刷新项目并选择 → 查询状态，与造价智算原界面逐项核对。
5. 填写摘要 → 送入对话 → 选择电脑朗读、小人文字或 Watch 朗读并手动执行。Watch 气泡限制 24 字/72 UTF-8 字节，动态朗读仍有 10 秒限制；不自动截断。

真实知识准确性、真实项目任务一致性、真实 AI 模型返回、摘要电脑/Watch 听验均待完成。本次未烧录、未访问云模型、未修改造价智算业务仓库、未创建业务任务或成果。停止仅保证本机不消费迟到结果，不保证上游已发起的模型执行被终止。

## 接口摘要

- `GET /api/cost/health`：检查造价服务身份及版本。
- `GET /api/cost/projects?page=1`：每页 20 项；要求工作台 UUID 所有权。
- `GET /api/cost/projects/{id}`：项目概况与业务任务白名单。
- `POST /api/cost/query`：`generation`、`question`（1–1000 字）、`allow_ai`（默认 false）。先通过既有 `/api/workspace` 获取控制权，不要求语音连接。
- `POST /api/desktop/stop`：既有全局停止，取消在途知识查询及其他操作。
