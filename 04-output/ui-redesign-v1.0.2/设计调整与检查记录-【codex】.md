# 顶部头像与模块标签原型 v1.0.2

日期：2026-09-23。用户在 v1.0.1 中标注两项要求：模块菜单放在原“当前会话”位置，点击切换；头像恢复旧版上方右侧位置。

## 当前调整

- 取消左侧大头像区域；动画头像移至工作区顶部右侧，默认约 100 px，较矮窗口 74 px，窄屏 58 px；继续使用正式 Grok catalog/renderer。
- 内容标题位置变为“对话 / 角色 / StopWatch / 设置”四个标签，顶部全局栏不再重复放这些菜单。
- 点击标签只切换同一块内容；共享头像节点不在任一 tabpanel 内，切换不重建、不重置头像。角色表情直接在上方头像本地预览，发送到设备仍为独立动作。
- 移除侧滑弹层的生成、遮罩、关闭按钮和焦点锁；标签具有 tablist/tab/tabpanel 语义及左右键、Home/End 切换。
- 内容宽度上限约 1000 px，输入及各模块底部操作继续采用可收缩内容区加固定操作区；不恢复三行介绍。
- 保留 v1.0.0/v1.0.1 历史原型，正式程序仍 v0.9.0-dev。

## 本次检查

- HTML UTF-8、ID 唯一、四个标签与四个内容面板双向关联检查。
- 两个内嵌脚本通过 Node 语法检查，静态 ID 引用存在；无外部脚本。
- 验证头像位于所有模块内容之前的共享工具区，无第二个预览头像；脚本不再访问已移除的预览节点。
- 删除原型的模态弹层语义及运行代码，避免标签导航与遮罩混用。
- 本版未完成浏览器视觉或窗口缩放实测；此前本地 file URL 预览受内置浏览器策略限制，未绕过。旧版尺寸结果不作为本版验收。
- 无真实麦克风、服务或设备调用。实际录音、AI、声音与硬件均非本次验证范围。
