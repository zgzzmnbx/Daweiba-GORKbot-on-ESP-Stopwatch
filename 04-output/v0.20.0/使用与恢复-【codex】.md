# v0.20.0 / v0.11.0 使用与恢复

当前是已写入、待设备启动/配网验收的候选。2026-10-04只写app0 0x10000，独立verify_flash通过。串口启动输出和BLE广播尚未观察到；先由用户确认屏幕，必要时退出烧录模式并正常物理重启。串口控制线会影响ESP32-S3 USB-Serial/JTAG，空白日志不能单独证明程序失败。不要清绑定或整片擦除来试错。

1. 电脑手动连接vivo200的2.4GHz热点；Watch Settings → Bluetooth 保留原可信PC绑定。新服务恢复后先做旧表情、短音与音量验证。
2. 正式控制台 → StopWatch → 取得控制权。在“热点与连接策略”填写掩码密码，点击安全配网。密码仅通过可信BLE发送给Watch，不从聊天、历史、脚本或仓库取用。等待“设备确认配置”，再等待Wi-Fi认证；热点连接自身不代表控制就绪。
3. 对话/设置连接现有语音会话，核对各路由与独立上传许可。对话页“启用 Watch 按键对话”默认关闭，明确启用后才委托；需要可用回答服务及回答文字许可。保持电脑页面会话有效。
4. 长按A触发新任务，等Watch显示REC再说话；松开发送、最多10秒。B停止整个本轮，A+B设置优先。新长按取消上一轮并建立新代际；断线不会重播旧答案。普通空闲不占用录音会话。
5. 回答超过10秒时保留完整PC文字，设备显示未播放原因。点击“生成更短回答”才再请求；不截断或自动分段。COMMIT后显示对应文字，再PLAY。
6. StopWatch可选Wi-Fi优先/仅BLE/仅Wi-Fi、auto/performance/eco。设备供电不能识别时显示unknown并eco，手动覆盖可保存。改变模式前停止设备任务。
