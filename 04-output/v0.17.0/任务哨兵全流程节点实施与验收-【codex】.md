# Gork 任务哨兵 v0.17.0-dev 实施与验收

## 实施

- 造价智算 v5.24.7 在实际转换、直接/批量匹配、经验池预警、Word/风险报告及协同复核入口记录持久化节点；GET 监控仍只读。飞书复核发起和双回执确认送达是两个节点，不把 HTTP 接受当作消息送达。
- Gork 首次读取仅建立基线，之后按事件编号去重并排队；工作 `working`、待复核 `curious`、成果完成 `happy`、失败 `confused`。气泡只含简短状态和已确认数量。
- 原声音开关保留；开启时默认使用 Windows 本机 `System.Speech` 中文语音生成固定短句，WAV 缓存在项目忽略的 `Codex-Temp/sentinel-speech/`，可选电脑或 Watch；也可切回短提示音。Watch 复用原音频传输、BLE 写锁及文字在 COMMIT 后、PLAY 前显示的时序。
- Watch 固件 v0.9.1-dev 和 Android v0.1.7-dev 未修改、未烧录或安装。未触发真实飞书投递。

## 待真人验收

用户重启 Gork 桌面程序后，以新网页任务依次检查转换、匹配、预警、报告和飞书复核。记录桌面表情/气泡、Watch 表情/气泡及电脑/Watch 可闻短句；飞书送达必须核对真实两项投递状态。重启会让 Watch 短暂断连重连，按用户之前选择由本人操作。源码、模拟回归、系统播放调用和设备回执不能代替实际听见。
