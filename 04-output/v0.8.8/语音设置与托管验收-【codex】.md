## 启动故障与修复

首版前台入口用阻塞 stdin 读监测父进程退出，Windows 下 HTTP 已在线但模型子进程一直 loading，45 秒就绪门禁失败。改成 Win32 `PeekNamedPipe` 非阻塞检测后，同机同模型约 9 秒完成整个启动、就绪、重复启动、退出测试。保留此真实失败和修复结果，不将单纯在线视为模型就绪。

## 使用与升级

1. 本次修改尚未自动强制重启用户正在使用的旧 8766 / 8765 实例；需用户确认一次性重启以加载新版。
2. 此后从项目根目录 `start-gork-console.cmd` 启动：语音服务没有运行时自动拉起；已运行则复用。不必每次另外打开语音程序。
3. 连接会话 → 声音与隐私选择 TTS 路径 → 音色与试听选择音色/语速 → 应用并保存 → 试听当前音色。
4. “停止试听”或主区“停止”立即停止本地播放并请求取消；云端已提交请求仍可能计费。
5. 旧 v0.8.0 发行包未更新；迁移电脑需单独配置独立语音服务入口，不宣称完全便携。
