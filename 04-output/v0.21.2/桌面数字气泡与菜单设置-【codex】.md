# 桌面数字气泡与菜单设置 — v0.21.2-dev

日期：2026-10-15。

## 使用入口和行为

控制台「设置 → 桌面小人 · 数据显示」可选常驻菜单或数字小气泡。默认数字模式并勾选Codex额度、今日token和代理网速。五项均可独立开关；全部取消只显示小人。常驻菜单沿用上一版状态/控制台/隐藏/流量信息栏。

数字窗独立于头像尺寸，按钮按文字收紧，最多每行三项。25%至150%桌面头像均不为数据缩小；随移动、缩放和置顶状态更新，隐藏/最小化停止读取。屏幕边缘及已有聊天/额度卡占位时自动避让。点击数字进入控制台，悬停提供指标、时间范围和收发明细。隐藏/退出入口继续在控制台和小人右键/托盘菜单。

| 选项 | 数字口径 |
| --- | --- |
| VPN总流量 | 今日Gork监测到的Clash代理上传+下载增量，不是套餐累计用量 |
| Codex额度 | 官方实际窗口中的最低剩余比例；悬停列出窗口名称与比例 |
| Codex token | CC Switch本机今日token，含缓存，十进制K/M/G |
| 普通网速 | 整机物理网卡上下载速度合计，含代理和局域网 |
| 代理网速 | Clash代理上下载速度合计 |

流量类K/M/G按1024换算，速度每秒；流量监测需由用户开启原有开关，勾选气泡不启动采集。额度/token仅在数字模式、被勾选且小人可见时每20秒只读请求已有接口，复用后端缓存；不启用哨兵、不接管会话。失败/过期显示—，不把未知当零。取消勾选、隐藏与退出丢弃迟到回执。

配置通过仅允许控制台调用的IPC写入原本机window-state.json，校验模式/白名单/重复项，保存失败回退；重开恢复空列表和菜单选择。浏览器或旧桌面桥接不可用时禁用并提示。
