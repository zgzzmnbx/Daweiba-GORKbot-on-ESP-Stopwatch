## 变更

右上角原「经典主题 / Mantine 主题」切换旁增加「配色」菜单。现有绿色继续作为首次默认值，提供以下选择：

| 名称 | 主色 |
| --- | --- |
| 原有绿 | `#16876A` |
| 清爽蓝 | `#228BE6`，即 RGB(34, 139, 230) |
| 靛蓝 | `#4C6EF5` |
| 青蓝 | `#15AABF` |
| 蓝绿 | `#12B886` |
| 紫色 | `#7950F2` |

颜色选择写入本机 `gork.console-color`，恢复时只接受上述值，非法值回到原有绿。选择只改变 Mantine 主题外观；经典主题里选颜色会切到 Mantine。经典主题本身及原 `gork.console-theme` 偏好保留。切换不刷新页面、不重建业务控件或设备连接。

Mantine 组件的主色、浅色/悬停/边框变体与页面背景、文字强调、焦点和表情选中态同步。按钮使用对应色系较深色阶，避免亮青色/蓝绿色配白字过淡。主题仅使用本地 CSS 和脚本，沿用原 CSP。

## 验证

- `npm run build:ui` 和 `npm run check:ui`：生成页面与源码、锁定 Mantine 依赖一致。
- `npm test`：85 项前端测试通过；新增颜色保存、经典主题选色切换、非法存储回退、存储不可用及草稿/控件身份保留测试。
- 隔离 Electron 窗口：1180px 与 390px 两种宽度逐一选择五个新颜色，核对实际色值、按钮色、菜单视口边界及无页面横向溢出。蓝色样本实际为 `rgb(34, 139, 230)`；其余分别为 `rgb(76, 110, 245)`、`rgb(21, 170, 191)`、`rgb(18, 184, 134)`、`rgb(121, 80, 242)`。
- 手动检查两张隔离窗口截图，蓝色主色、背景、导航、选择菜单和窄窗口布局可见。隔离替身不等于正式程序现场验收。
