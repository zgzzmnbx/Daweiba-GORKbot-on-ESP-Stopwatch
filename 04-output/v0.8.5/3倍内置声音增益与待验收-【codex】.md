# v0.8.5-dev 3 倍内置声音增益与待验收记录

> 2026-09-23。用户确认 v0.8.4 本地 Sound/Test 已真实出声，但 100% 音量仍偏小，希望在现有基础上约放大 3 倍。本版已完成源码修改、音频资产重生成、自动回归和 PlatformIO 构建，并按用户当次“授权烧录 v0.8.5”仅写入设备应用区；独立读回校验通过，真实响度和失真待人工验收。

## 1. 增益方案

- 六个内置声音原始 PCM16 峰值均为 `10,000`，PCM16 上限为 `32,767`，理论无削波余量为 3.2767 倍。
- 将生成器峰值统一提高到 `30,000`，即数字幅度精确 3 倍，约 `+9.54 dB`；六个生成 WAV 和固件头文件同步重建。
- 保持 ES8311 DAC 音量为 0 dB，不提高 codec 全局增益；因此本版只影响六个内置声音，不会把动态语音、BLE PCM 或录音回放一起推入削波。
- 保留 50 ms 静音引导、淡入淡出、时长、频率、声音 ID、BLE 协议和 0–100 音量设置不变。

“数字幅度 3 倍”不等同于人耳主观响度严格 3 倍；最终响度、失真、杂音及扬声器负担必须以真机听验为准。

## 3. 当前门禁

- 固件源码、归档镜像和设备应用区均为 v0.8.5-dev。
- 写入前重新识别 COM5：ESP32-S3 QFN56 rev0.2、16 MB Flash、8 MB PSRAM、MAC `28:84:85:44:6C:00`；从设备读取分区表，确认 app0 为 `0x10000`、容量 6400 KiB。
- 使用 esptool.py 4.9.0、460800 波特率，仅将 1,625,456-byte 应用镜像写入 `0x10000`；烧录器报告 `Hash of data verified`，独立 `verify_flash` 返回 `verify OK (digest matched)`，随后硬复位，COM5 重新枚举正常。
- 未执行整片擦除，未修改分区、NVS、bootloader、eFuse 或安全配置。
- 真机请先将音量降到 30%–40% 试听，再逐级提高至 100%，检查响度、破音、爆音、底噪和异常发热。
- 只有真机确认响度提升且音质可接受，才能关闭最大音量偏小问题；构建和无数字削波不代表扬声器不会产生模拟失真。
