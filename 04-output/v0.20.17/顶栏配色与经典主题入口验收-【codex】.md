## 变更

Mantine 顶栏现随原有绿、清爽蓝、靛蓝、青蓝、蓝绿、紫色六种配色同步改变浅色背景、下边线、GORK 字色和连接就绪标签。离线文字使用灰色，停止操作继续使用警示色。顶栏右侧只保留常用「配色」菜单。

「经典主题 / Mantine 主题」切换按钮移至设置页底部的「界面外观」。按钮仍使用原 `theme-toggle` ID 和 `gork.console-theme` 本机偏好；切换仅改变样式表状态，不刷新页面或重建对话、头像和连接。经典主题自身外观保留原配色。经典主题下从顶栏选颜色仍会返回 Mantine 主题并应用所选颜色。

## 验证

- `npm run build:ui`、`npm run check:ui`：生成的 Mantine 页面与模板及本地依赖一致。
- `npm test`：85 项前端回归通过；主题专项确认切换按钮仅位于设置页、右上角配色仍存在、草稿/控件身份/偏好保留。
- 隔离 Electron：1180px 和 390px 宽度下逐一选择五种新增颜色，顶栏背景均互不相同，品牌字色与就绪标签随色变化，离线文字保持中性灰；菜单位于视口内，无页面横向溢出。
- 隔离 Electron 设置页：按钮位于「界面外观」卡片内、可见且未越界；切换至经典主题后顶栏恢复经典外观，再切回 Mantine 时原配色保留。窄窗口截图已人工查看。隔离数据替身出现的接口提示不属于正式程序验收。
