## 实施

右上角增加「暗色模式 / 浅色模式」按钮。选择写入本机 `gork.console-scheme`，启动时先恢复外观，再执行页面业务逻辑。原有绿、清爽蓝、靛蓝、青蓝、蓝绿、紫色均适用，顶栏、工作区、输入栏、设置卡片、配色菜单和连接状态同步使用暗色表面及对应强调色。经典主题仍用原外观；返回 Mantine 时恢复此前的明暗与配色。

切换只更新根元素属性及样式，不重建控件、不清空草稿或对话，也不触发设备和云请求。模板是 `ui/console.html`；行为见 `static/console-theme.js`，暗色规则见 `static/console-dark.css`。构建脚本保持本地样式资源及现有严格 CSP。

## 验证

- `npm run build:ui`、`npm run check:ui`：通过，生成页与模板和锁定依赖一致。
- `npm test`：87项前端回归通过；新增明暗偏好恢复、经典主题往返、被禁用的本机存储、配色与草稿保持断言。
- 隔离 Electron：1180px、390px 各遍历六种暗色配色；顶栏深色背景逐色不同，页面、卡片、输入栏及配色菜单均为暗色；按钮留在窗口内，无横向溢出。检查明暗往返后保留配色，并人工查看桌面、窄屏对话和窄屏设置画面。
- 隔离接口返回占位数据，截图中的服务错误提示来自替身，不代表正式程序健康状态。本轮未做正式窗口操作、真实云请求、Watch 实屏或设备控制验证。
