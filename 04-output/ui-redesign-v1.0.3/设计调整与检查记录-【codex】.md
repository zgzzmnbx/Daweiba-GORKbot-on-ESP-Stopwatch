# 左侧机器人与右侧标签页原型 v1.0.3

日期：2026-09-23。按用户最新反馈，替代 v1.0.2 的上方头像方案。

- 左侧约四成常驻项目正式动画机器人；右侧约六成，顶部为对话、角色、StopWatch、设置标签。
- 标签仅切换右侧内容，左侧头像处于共享区域，切换不重建或重置；无侧滑弹层、遮罩或模态焦点锁。
- 角色标签在左侧头像预览，不增加第二个头像；录音和设备仍是模拟交互。
- 内容总宽上限约 1160 px，保留底部固定输入/操作；仅窄屏收成顶部紧凑伙伴区。
- 按用户追加要求，在机器人下方增加语音/设备/朗读方式状态、自动朗读/表情联动/桌面小人三个快捷开关及设置入口；开关仅演示，实际桌面窗口不受影响。
- 默认云端朗读、本地识别；云端示例音色明确标注，自然语速 1.0×，云端时禁用本地音色分类与变速。保存设置后才更新左侧与对话区的路由摘要。
- 静态检查确认三个 switch、云端朗读 selected、全部元素 ID 唯一且脚本 ID 引用存在；两份脚本语法检查通过。原型不发云请求。
- HTML ID 唯一、四组标签/面板关联、共享头像与右侧区域分离、静态 ID 引用检查通过；两个内嵌脚本通过 Node 语法检查。
- 本版未完成浏览器视觉与窗口缩放实测，旧版结果不作为当前验收。正式程序仍 v0.9.0-dev，未修改运行实例、外部语音服务或设备。
