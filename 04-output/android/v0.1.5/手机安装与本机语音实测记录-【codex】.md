# Gork Android v0.1.5-dev 手机安装与本机语音实测记录

日期：2026-09-27。用户接入手机后开展本轮验证；按用户要求，开发停在现有功能范围，不继续新增云语音、Opus、后台服务或悬浮伴侣。本轮未迁移 Watch 绑定、调用云端、使用个人 Key 或写入固件。

## 设备与安装

- ADB 识别设备序列 `10AEAZ35S30014C`，型号 `V2405A`，Android 16 / API 36，物理显示 1260×2800、密度 560 dpi（宽约 360 dp）。设备型号按系统回报记录，不据此推断商品名。
- v0.1.4-dev（versionCode 5）首次 `adb install -r` 成功，冷启动后 Gork 进程与四标签页面可见；手机上 `com.dabawei.flashnote` 仍已安装。本轮没有读取或比对闪念私有数据。
- v0.1.5-dev（versionCode 6）在 vivo“安全守护”外部来源安装确认页等待用户本人确认后，`adb install -r` 报 `Success`。安装包 [Gork Android v0.1.5-dev 调试包](Gork-Android-v0.1.5-dev-debug-【codex】.apk) 的 APK v2 签名验证通过；手机包管理器回报 versionCode 6、versionName `0.1.5-dev`。这是开发调试签名，不是正式发布签名。
- v0.1.4 冷启动与 v0.1.5 同签名覆盖升级后，原“你好”草稿仍在；v0.1.4 冷启动后主题选择仍为“深色”，角色气泡没有自动重播。Watch 始终显示未连接。A05/A19 仅覆盖上述字段与这一次升级，不代表全部设置和回退已验收。

## 本机语音与权限

- 目标手机的系统中文 TTS 检测返回音色 `zh`。用“你好”执行完整文件导出，页面回报 PCM16 单声道、24 kHz、0.87 秒、41600 字节；私有缓存中未见本模块残留音频文件。用户表示未留意手机朗读声音，所以**实际可闻、清楚完整仍未确认**，A14 不标 PASS。
- 设备端 ASR 探测返回不可用。v0.1.5 修正了权限顺序：服务不可用时先返回 `ON_DEVICE_ASR_UNAVAILABLE`，不再申请麦克风。验证时临时撤销 Gork 麦克风权限，冷启动并点按“按住说话”，页面返回该错误且前台仍为 Gork，无授权弹窗；随后恢复原先已授予的麦克风权限。该手机没有完成中文语音转写，A12 不标 PASS。
- 附近设备权限已获系统许可；扫描时未发现 GorkBot-SW。没有发起配对、清绑定或设备命令。Android 原生 GATT、音频播放及电脑恢复流程均未验证。
- 云配置页显示无个人 Key，四项上传许可均关闭；未执行 AI 网络请求。无 Key、断网、额度与真实回答仍需 A13 实测。
