# USB 首次配网与 Wi-Fi 优先 — PC v0.20.1-dev / Watch v0.11.3-dev

2026-10-04。用户最新要求：电脑与 Watch 同连 vivo X200 手机热点，先实现 Wi-Fi 互联；原 BLE 能力必须保留。同时隐藏普通表情页底部待机音频提示。

## 实现

- 新增本机 USB 首次配网。运行态 HELLO 验证设备协议后，PC先保存 Windows DPAPI 保护身份，再写入 Watch 独立 gorknet 配置；沿用 TLS 1.2 PSK 认证与 Wi-Fi 优先策略。
- 固件串口输入定长、有请求号、CRC及长度/身份检查；配网内容不回显，播放/录音忙时拒绝配置。旧短表情串口命令保留。打开串口前关闭 DTR/RTS，不主动进入下载模式。
- 控制台默认 USB，可切换既有可信 BLE 配网；密码为掩码输入，点击后清空，PC配置不保存热点密码。现场电脑当前热点名为 vivo X200 Pro（2.4GHz）。
- 普通表情页空闲时底部提示为空，录音倒计时和正在工作的音频提示保留；设置页固件版本显示 v0.11.3-dev。
- BLE服务顺序继续保留三个旧服务范围；未清绑定、未放宽 GATT 认证。Windows完整发现问题尚未解决，不能称 BLE 已恢复。

## 操作与恢复

1. 正常重启Watch并保持USB连接；确认Settings版本。
2. 正常打开Gork，StopWatch页取得控制权；USB配网、热点vivo X200 Pro，密码仅填本机框，点安全配网。
3. Watch获得热点IP，PC显示Wi-Fi已认证后发一次表情，检查真实回执与实屏。
4. 需要回退时使用04-output/v0.11.2/firmware中的旧app镜像；回退新写入须另次授权，不清绑定。源码变更前备份在Codex-Temp/wifi-usb-v0201/baseline。
