# 桌面小人鼠标跟随验收

版本：PC v0.20.32-dev。日期：2026-10-12。

## 行为与入口

控制台「设置 → 交互与桌面 → 鼠标跟随」，默认开启。开关即时生效，关闭选择保存到桌面原有 `window-state.json`；重载控制台或重新启动桌面程序仍恢复已保存选择。普通浏览器或旧版桌面桥接不支持时，控件禁用并说明仅桌面客户端可用。

待机 / 内置聆听表情平滑看向鼠标，鼠标离开小人窗口仍可跟随。算法参考 `D:\Codex-Temp\260613-【智算Astra】\03-Src\studio\gork-pointer.ts`：响应时间260ms、转向速度上限90度/秒、左右35度/上下28度；鼠标静止约2.2秒后淡回原动画。思考、开心、错误、显式其他表情与自定义加载/书写/疑惑场景保持原动作，跟随不接管它们。减少动效偏好关闭此跟随动效。

## 实现

- `03-Src/gork-desktop/cursor-tracker.js`：使用Electron `screen.getCursorScreenPoint()`，50ms采样；只有坐标、窗口位置/尺寸或显示器变化才发送。使用窗口和显示器的DIP坐标，避免乘DPR导致偏移；不读取点击、键盘或内容。
- `main.js` / `preload.js`：单向桌面坐标事件与受限控制台开关IPC。关闭/隐藏/最小化/退出停止采样；开启/恢复/重载补发当前位置且不叠加计时器。开关保存失败保持此前状态。
- `gork-pointer.js` / `avatar.js`：在桌面适配层混合原姿态，沿用播放器已有RAF，不修改导出的共享渲染资产、用户表情参数或Watch。
- `ui/console.html` / `static/app.js`：复用既有设置开关样式与读取/保存逻辑，模板构建生成 `static/index.html`。

Electron官方坐标说明：[screen API](https://www.electronjs.org/docs/latest/api/screen)。
