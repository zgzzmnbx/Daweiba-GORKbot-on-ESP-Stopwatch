# 单页自适应原型布局验证

日期：2026-09-23。设计原型 v1.0.0；验证对象是本目录 HTML，不是正式 v0.9.0 程序。

## 已完成

- 使用独立 localhost 8877 静态预览；仅服务本原型目录，未重启 8766/8765 正式实例。
- 六种正常视口 × 四种状态（主界面、角色面板、设备面板、设置面板）共 24 组检查：1180×820、1366×768、1024×600、820×600、390×700、390×540。document/body 均无横纵溢出，主输入和面板底部动作均在视口内；长面板只在内部滚动。
- 另测 683×384 极矮视口四种状态：document/body 无溢出，按设计退化为内部工作区滚动，底部动作不强求首屏可见。角色面板通过 Shift+Tab 导航到末尾操作验证键盘滚动可达；不是实际浏览器 200% 缩放实测。
- 1180×820 下添加 12 条较长测试输入，加原有示例共 14 条消息，消息 scrollHeight 2038、clientHeight 472；消息区已滚动，body 仍高 820，输入下沿约 767 px，保持可见。
- 设置侧面板修改语速后保存按钮启用、试听禁用；保存后恢复。设置仅存原型内存，未访问真实语音配置。
- 主输入草稿在面板打开/关闭后保留。Escape 关闭后焦点回到“设置”入口；角色面板 Tab / Shift+Tab 首尾循环通过。
- 桌面主界面、角色与设置侧面板、390 宽主界面已截图并目视检查。检查期间修正工作区垂直居中造成的多余留白、窄屏品牌隐藏及关闭面板焦点未返回问题。
- 浏览器捕获的 error 日志为空。未触发真实麦克风权限、AI 请求、音频播放、蓝牙扫描或设备操作。

## 结论边界

布局原型可用于评审单页/侧面板方向；当前生产源码和设备均未改变。原型中的服务、录音、设置保存、设备连接均有模拟标识。完整 24 项表情目录、真实音色检索收藏、AI 消息流程、真实取消边界等按 PRD 分阶段实施。

尚未验证：正式 Electron 原生窗口、多显示器/DPI、实际浏览器 200% 缩放、手机软键盘、真实录音听感、云端和 BLE 设备；原型测量不能替代这些验收。
