# 常驻机器人原型 v1.0.1

日期：2026-09-23。响应用户“机器人头一直在界面里动、聊天页面太大”的反馈。

## 调整

- 左侧常驻项目正式 Grok 动画角色，约占四成；右侧聊天约占六成，内容宽度上限约 1160 px。
- 删除上一版隐藏欢迎区，将原来的 chat-face Canvas 移入可见伙伴区；idle 使用原渲染器持续播放。打开其他面板不重置主角色状态。
- 增加打招呼与表情入口；打招呼使用正式 happy 序列一次播放，按来源序列时长回到待机状态说明；不伪装成设备执行。
- 录音按钮仅模拟 listening/idle 外观，不访问麦克风；全局停止回 idle，不取消待机动画。
- ≤680 px 改为顶部紧凑伙伴区，≤560 px 高再压缩；不恢复三行大标题，继续保留底部输入与局部滚动设计。
- 旧 v1.0.0 文件保留，当前生产代码仍 v0.9.0-dev，未改外部语音服务、固件或运行实例。

## 检查与限制

- HTML 使用 UTF-8，元素 ID 无重复；两个内嵌脚本通过 Node 语法检查；未引用外部字体/CDN。
- 内嵌角色 catalog 与 renderer 来源与 v1.0.0 相同；主角色恢复为可见，复用项目正式 mount/set/once 接口。
- PRD、README、当前计划、AGENTS、CHANGELOG 的当前设计指向已同步 v1.0.1。
- 内置浏览器安全策略拒绝新版 file URL 预览，未尝试绕过；未完成本版视觉、连续动画或窗口缩放实测。旧版六种窗口尺寸结果不能当作本版验收。
- 所有服务、语音与设备按钮仍为原型模拟，无云请求、麦克风录音或设备操作。
