# v0.6.0 电脑语音工作台实施说明

日期：2026-09-20。依据冻结交接任务书和语音服务协议 v1.0.0。用户授权先备份当前固件、再开始开发；本版只开发电脑端，设备固件仍 v0.5.0。

## 用户闭环

启动独立语音服务 → 双击工作台 → 连接会话 → 电脑录音 → 完整 WAV 转写 → 人工编辑 → 电脑回读 → 自动待机。可选择连接 StopWatch，同步聆听、思考、说话、错误和短气泡；未连设备仍可完成电脑闭环。

不做自由 AI 问答、业务检索、设备自身录音/扬声器、语音唤醒、逐音素嘴型或固件升级。

## 模块与边界

| 模块 | 文件 | 责任 |
| --- | --- | --- |
| 语音适配 | `companion/voice.py` | 仅 HTTP；session/turn、ASR multipart、完整 TTS WAV、取消、超时、错误码；不读取其他仓库配置/模型/Key |
| 交互状态 | `companion/control.py` | 页面所有权、递增 generation、请求集合、异步取消、旧结果隔离；ASR/TTS 同 turn 不同 request_id |
| 蓝牙适配 | `companion/robot.py`、根目录 `tools/stopwatch_ble.py` | 发现、配对、单写入者、有限重连、短气泡和严格回执；不改 BLE 固件 |
| 同源接口 | `companion/app.py` | Host/Origin 验证、输入限制、页面控制标识、语音令牌不暴露网页 |
| 网页音频/UI | `static/` | WebAudio/AudioWorklet 采集与重采样、可编辑文字、完整音频播放、即时本地停止、独立上传许可 |
| 启动与配置 | `run_companion.py`、根目录 `start-voice-companion.cmd` | 独立环境、回环监听、自有实例/PID 检查、不结束其他服务；可配置端口和设备预选 |

除特别标记路径外，文件相对 `03-Src/stopwatch-voice-companion/`。

## 必须保持的不变量

- 默认 `replace=false`；409 时只提示，显式用户接管才传 true。会话失效停播，不自动抢回。
- ASR 和 TTS 路由、录音上传和文字上传分开；新会话两许可归零。取消勾选即停止并撤销许可，不等用户再次点应用。
- 实际转换 PCM16/单声道/16 kHz WAV，0.1–30 秒、≤2 MiB；TTS 完整 WAV 解码成功且本地播放器启动后才发 speaking。
- 服务端完成不等于播放完成；本地停止先于网络取消；旧 HTTP/播放器回调不可复活已结束操作。
- 气泡只截取设备预览，不截断 PC 原始转写/回读。超 300 字的回读明确拒绝，保留原文供编辑。
- BLE 连接掉线不阻断 PC 语音；两次自动重连后停止重试，只恢复最新状态，不重放旧气泡/音频。无法确认回执时显示未确认。
- 不将已发送到设备的包宣称可撤销；最新 idle/清屏随后覆盖。现有表情回执无事务号的协议边界继续明确记录。
- 备份和私有配置不入 Git。固定绑定本机 HTTP，不开放通配 CORS、不读云 Key。

## 人工验收清单

1. 麦克风授权后说一句包含数字的话，确认文本完整，编辑后能回读；30 秒自动停止。
2. 回读中按停止，确认立即静音；立即新录音，旧声音不再出现。
3. BLE ON、首次 Pair、退出设置，连接后观察 listening/thinking/happy/idle 和中文短气泡；断开设备后 PC 仍能跟读。
4. 两种上传许可分别撤销，确认对应云路径退回本地。实际云端请求与费用仅在用户授权后测试。
5. 与另一语音页面切换控制权，确认旧工作台停止且不会自动抢回。
6. 固件既有气泡实屏、happy-work 观感、FPS、陌生端拒绝与长期稳定性按历史 PRD 继续补测。
