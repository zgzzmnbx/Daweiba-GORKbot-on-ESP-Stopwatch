# StopWatch Grok Avatar（个人版）产品总览 PRD

> 产品代号：Grok Avatar for StopWatch  
> 目标硬件：M5Stack StopWatch C152  
> 使用范围：大尾巴个人、非商业、本地使用  
> 当前开发版本：v0.2.0

## 1. 产品愿景

把 M5Stack StopWatch 做成一个具有生命感的圆屏角色终端：开机后不是静态表盘，而是一个会观察、眨眼、呼吸、弹跳、思考、回应触摸并感知设备姿态的 Grok 风格小机器人。

第一阶段重点是“角色活起来”，不接入云端和语音大模型。后续可在稳定动画引擎之上增加麦克风、扬声器、唤醒词和对话能力。

## 2. 已确认决策

- 以 `Trentct/m5stack-stopwatch-avatar` 的 KK 程序化头像工程作为硬件和动画底座。
- 采用 PlatformIO + Arduino + M5Unified/M5GFX 技术栈。
- 可以在个人项目中复制和转换 `blessonism/grok-icon-study` 中的 Grok 造型、几何和视觉资产。
- 产品仅供个人、非商业使用；工程代码按未来可开源维护，不规划闭源或商用版本。
- 本版本直接复制和转换 Grok 参考资产，不把第三方资产限制作为开发阻塞项；来源与提交号仍需保留。
- v0.2.0 只做本地开发，不在本版本执行公开发布；未来开源发布的具体打包范围另行决定。
- 首次烧录仍需单独确认；本轮 PRD 不授权烧录。

## 3. 核心体验

- 角色始终保持轻微呼吸、随机扫视和自然眨眼。
- 眼睛跟随手指触点和设备倾斜方向。
- 点击、双击、长按、滑动、按键和摇晃触发不同表情。
- 表情之间采用连续弹簧和关键帧过渡，不使用生硬切图。
- 纯黑背景利用 AMOLED 特性突出角色，同时控制无效刷新和功耗。
- 角色能够通过振动对关键交互给出即时反馈。

## 4. 阶段路线

- v0.2.x：建立可编译工程，复现 KK 基线，完成 Grok 几何接入和桌面/静态验证。
- v0.3.x：经确认后首次烧录，完成显示、触摸、IMU、按键、振动和帧率真机验收。
- v0.4.x：完善角色动作、低功耗、RTC 和个性化配置。
- v0.5.x：评估语音输入、音频播放和小智/大模型接口。
- v1.0.0：由大尾巴明确决定正式版本范围。

## 5. 产品边界

当前不包含：云端账号、聊天服务、联网大模型、离线语音识别、摄像头、舵机、量产、商用发布和应用商店分发。
