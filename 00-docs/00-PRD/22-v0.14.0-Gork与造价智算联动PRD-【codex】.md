# Gork × 造价智算联动 PRD

文档 v1.0.0 · 2026-09-26 · 目标控制台 v0.14.0-dev

## 定位与边界

Gork 提供入口、角色、语音和 Watch 输出；造价智算负责知识检索、业务数据与业务规则。功能界面进入电脑端 Gork 的“造价助手”标签页，不将完整业务界面搬到圆屏，不复制造价引擎、数据库或语音引擎。

首版提供知识检索、显式授权的知识问答、项目列表和项目任务查询。禁止自动计价、改价、确认系数、写入成果、创建业务任务和发送报告。不增加设备固件能力，不烧录、不重启正式实例、不部署云端。

## 用户流程

1. 用户手动检查造价服务连接，取得本工作台控制权。
2. 知识问题默认只检索本地依据。用户单次勾选“允许 AI 整理”才调用上游问答；问题及检索依据可能交给造价服务配置的模型，独立于 ASR/TTS 授权。
3. 界面完整保留回答、出处、是否找到依据及回答类型。预设演示回答明确标识，不能冒充实时检索；无依据不能称权威答案。
4. 项目查询通过列表明确选择项目 ID，再查询项目详情及任务；项目 ID 不自动当作知识库 project_key。
5. 用户编写/确认短摘要后，送入既有“对话”输入，复用电脑朗读、桌面气泡、Watch 气泡及延迟朗读。默认不自动播报业务内容；不截断数字、金额或单位。Watch 原有长度和时长限制保持。
6. 语音输入沿用对话页录音/识别；在造价助手点击“带入对话文字”后明确发起查询。首版不自动提交转写。

## 接口与模块

新增独立 CostClient，仅依赖 HTTP，不依赖 BLE、ASR、TTS、模型与业务数据库。Gork 后端同源转发固定白名单，不提供任意 URL/方法代理。造价服务地址仅支持 loopback HTTP，默认 127.0.0.1:8000，禁用重定向及环境代理。

复用已核对的造价智算接口：GET /api/health（service=guankanzhisuan）、GET /api/projects（分页）、GET /api/projects/{id}、GET /api/projects/{id}/tasks、POST /api/knowledge/search、POST /api/knowledge/ask。检索显式 classic，不启用混合模型检索；查询可能产生上游命中审计，但不修改业务成果。现有接口足够，无须为“预留接口”重复新增接口。

对外结果按白名单提取，禁止向前端返回上游 debug、请求头、模型提示词或凭据。出处按文本显示，不执行 Markdown/HTML。项目数据仅内存显示，不存 localStorage、不进入状态日志。

查询要求工作台所有权，不要求语音连接。继承 generation 过期与全局停止取消；停止客户端等待不保证上游模型已终止，必须在说明中明确。超时、离线、身份不匹配和无依据分别可辨。

## 实施计划与验收

- P1：接口适配、固定地址校验、服务身份校验、字段脱敏白名单、假服务契约测试。
- P2：同源接口、所有权/generation/取消门禁、无语音模式测试。
- P3：新增标签页，保留左侧动画；查询、出处、项目状态、摘要转入既有输出路径；沿用当前浅色风格。
- P4：后端及前端回归、隔离界面验证、文档与版本、本地 Git 存档。
- 人工门禁：真实造价实例的知识与项目数据准确性；用户明确授权后的模型问答、语音及 Watch 听验。自动测试不得替代这些门禁。

成功标准：默认查询绝不调用 ask；明确授权才允许 ask；不自动访问云端或发出声音；无语音/无 Watch 时可独立检索；出处与预设演示标识不丢失；停止后迟到结果不回填；项目读接口不能转化为写接口；原对话/角色/设备测试通过。
