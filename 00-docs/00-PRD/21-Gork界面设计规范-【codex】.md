# Gork 界面设计规范

## v0.12.4 修订：常驻状态终端与分栏

桌面左栏最大320px，两栏间距24px，左栏右侧1px细分隔；保留米白/橄榄绿基底。角色下方增加可折叠只读终端，默认深底浅绿等宽文字，可切白底深绿，主题独立保存。日志内部滚动、120条上限、逐通道状态去重；用户翻看历史时不自动拉回末尾，不输出聊天正文或原始异常。重复状态卡文字改为无障碍摘要，原开关/大小调节仍在。窄屏常驻区限定高度并内部滚动，右侧标签内容独立滚动；不得挤出全局停止按钮。

文档 v1.0.0；适用电脑端 v0.11.1-dev。风格：米白背景、橄榄绿主操作、克制的边框与层次。保留左侧常驻角色、右侧标签工作区。

## 空间和尺寸

| 项目 | 标准 |
| --- | --- |
| 间距刻度 | 4 / 8 / 12 / 16 / 24 / 32 px，统一用 CSS 变量 |
| 卡片内部留白 | 常规 24 px，小屏/矮窗口 12 px |
| 输入区块之间 | 桌面 16 px，矮窗口 12 px，小屏且矮窗口 8 px |
| 常规操作高度 | 40 px；矮窗口至少 36 px |
| 控件圆角 / 面板圆角 | 8 / 14 px |
| 输入文字 | 15 px，行高 1.7；输入框内边距 12×16 px |
| 辅助文字 | 11–12 px，行高不低于 1.6，说明不与输入内容竞争 |

## 输入区结构

1. 顶部模式选择与用途说明，模式控件独立成组。说明允许换行，不挤压选择框。
2. 独立白底输入框，聚焦仅变更自身边框及轻量外环；预留间距，外环不得贴邻近控件。
3. 左侧字数、右侧录音/停止/主提交；按钮有主次，间隔 8 px。空间不足允许换行。
4. 快捷键与录音时长提示独立底行，通过细分隔线和 12 px 上间距分开。

禁用控件不使用整组透明度叠加；采用明确的灰绿背景/文字。输入框关联字数和键盘说明，所有功能按钮保留文字，图标不替代名称。键盘焦点保留可见提示。

## 维护要求

CSS 定义 `--space-*`、`--control-height`、`--radius-*`、`--focus-ring`。优先修改组件规则和响应式断点，不追加覆盖层掩盖旧规则。不得为增加留白破坏窗口下沿适配：页面无整体滚动，长内容在工作区内部滚动。

## 本次验证

正式页面隔离预览 1346×986、1180×820、800×540、390×540 均无横纵整体溢出；输入框上下间距依次 16/16/12/8 px，主按钮和输入区底部在视口内。桌面输入“你好”并聚焦截图检查通过。既有浏览器/音频回归 21/21 通过；本轮仅样式/HTML辅助结构，未修改语音、设备或桌面小人行为。

## v0.11.2 修订：减轻输入区视觉重量

用户反馈四层卡片过于厚重。输入区改为单层细边框：移除背景色块、阴影、内部输入边框和分隔线；输入正文默认高度 72 px，主操作 34 px，保留 12 px 区块间距、16 px 内边距。快捷键提示移到框外，录音/停止使用无框次要操作。此修订优先于上文输入区 40 px 控件和嵌套输入框规则，其余模块规范保持。
