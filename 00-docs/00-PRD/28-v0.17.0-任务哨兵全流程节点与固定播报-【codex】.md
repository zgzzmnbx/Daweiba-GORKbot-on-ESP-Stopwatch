# v0.17.0 任务哨兵全流程节点与固定播报

## 范围

造价智算 v5.24.7 在真实业务入口记录转换开始、匹配开始和结果、预警开始和结果、报告生成、协同复核发起；复核送达须由现有投递表的成果和复核卡片两项 `sent` 回执确认。Gork 只读取事件，不执行匹配、生成报告或发送飞书消息。首次连接、断线恢复只建立基线，不补播旧事件。指定任务模式仅处理所选任务。

## 提醒矩阵

| 节点 | 桌面与 Watch 短文本 | 表情 | 固定播报 |
| --- | --- | --- | --- |
| 转换开始 | 开始转换，正在识别表格。 | working | 开始转换 |
| 匹配开始 | 开始匹配，正在核对规则。 | working | 开始匹配 |
| 匹配完成，有待复核项 | 匹配完成，N 项待复核。 | curious | 匹配完成，请复核结果 |
| 匹配完成，无待复核项 | 匹配完成，请查看结果。 | happy | 匹配完成，请查看结果 |
| 预警开始 | 正在运行经验池预警。 | working | 开始运行预警 |
| 预警结果，有需关注项 | 预警完成，N 项需关注。 | curious | 预警完成，请查看结果 |
| 预警结果，无需关注项 | 预警完成，请查看结果。 | happy | 预警完成，请查看结果 |
| 报告生成 | 报告已生成，请查看成果。 | happy | 报告已生成 |
| 复核发起 | 飞书/协同复核已发起，等待投递确认。 | curious | 飞书/协同复核已发起 |
| 复核送达 | 飞书/协同复核已发送，请等待同事反馈。 | curious | 飞书/协同复核已发送 |

匹配或预警失败使用 `confused` 和“未完成”短句，不给出成功文案。报告生成不代表人工通过；复核发起不代表已送达。数量仅用智算已提交的非负整数。

## 声音和优先级

声音开关仍继承本机保存值，启用后默认选择本机固定短句播报，可手选旧短提示音；声音位置为电脑或 Watch。Windows `System.Speech` 中文语音只在本机合成固定短句并缓存于忽略目录，不上传任务内容。Watch 复用现有音频传输及 COMMIT→文字→PLAY 时序；手动操作与正在进行的语音、Watch 音频优先。自动提醒排队、去重，并可由关闭哨兵取消。固件和 Android 不变。

## 验收

测试应覆盖七类节点、失败文案、事件去重与旧任务基线、飞书双回执、固定 WAV 格式、UI 版本一致性。Python/Node 测试和本机音频文件生成只证明源码路径；正式智算与 Gork 双进程、桌面实屏、Watch 表情和实际可闻仍需真人验收。
