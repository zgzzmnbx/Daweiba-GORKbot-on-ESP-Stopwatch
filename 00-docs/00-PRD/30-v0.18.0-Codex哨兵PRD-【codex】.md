## 2. 产品目标与范围

用户在现有 Gork 中查看 Codex 是否工作、是否需要人工、当前监测账号额度与重置时间；关键变化可输出桌面/Watch 表情、短气泡和可选短音。额度环是账号指标，绝非任务进度。

本版包含：只读适配、来源状态、任务列表/关注、额度多桶选择与窗口、通知调度、控制台、桌面环、Watch 现有协议输出、配置与卸载说明、自动回归及隔离验证。

不包含：通过 Gork 发起或继续 Codex 工作、审批代答、账户登录/登出、购买额度/消耗重置权益、改 Codex 安装文件、云端部署、手机开发、设备刷写、新 BLE 客户端。无需复制业务数据库、聊天正文、源代码或认证文件。

## 3. 用户操作与默认值

在现有控制台增加独立“Codex 哨兵”区域或标签页，保留造价助手原功能与偏好。避免因入口整理重写现有六页。

| 设置 | 默认 | 规则 |
|---|---|---|
| Codex 监测 | 关闭 | 每次后端启动保持关闭；其他偏好可持久化。与造价哨兵默认开启规则分离 |
| 任务跟随 | 自动 | 仅在已观测活跃任务中选择；当前关注保持稳定，不随每个事件跳转 |
| 指定任务 | 空 | 下拉或合法 ID；任务消失显示未知，不擅自改为别的任务 |
| 提示目标 | 桌面 | 可选 Watch/两端；离线结果单独记录 |
| 声音 | 关闭 | 本版复用短音；不自动生成云 TTS、不冒充 Cherry 缓存 |
| 声音目标 | 电脑 | 可选 Watch，一次只选一个声音目标 |
| 额度阈值 | 剩余 20% | 可设 1–99；仅新鲜数据触发，5 个百分点回差 |
| 额度刷新 | 120 秒 | 开启时一次、手动刷新合并请求；失败指数退避最大 15 分钟 |
| 额度环 | 不显示 | 可选“不显示 / 显示 / 鼠标悬停显示”；悬停模式在桌面小人上悬停或键盘焦点进入时显示；监测关闭时隐藏/停用；有一窗口单环、两窗口双环，多桶选择不混合 |

v0.18.1 修订：旧版布尔开关默认开启，不能证明用户曾主动选择显示。读取旧本机偏好时保留其他设置，旧 `show_ring` 不迁移为显示；未保存三档偏好的用户默认“不显示”。该选项仅控制桌面小人的额度环与其详情入口，控制台额度数值仍可读取。

显示“任务通道”和“额度通道”各自的未启用/连接中/可用/部分可用/过期/不可用。详情包含来源、采样时间、窗口时长、重置时间和范围“当前监测账号额度”。不显示邮箱、token 或完整路径。缺少 hook 信任时提示具体操作，绝不伪报已接通。

## 4. 任务事件与状态规则

### 4.1 归一化记录

最小结构：source、source_instance、thread_id、turn_id（允许未知）、event_id、kind、occurred_at、observed_at、capabilities、sanitized_label。展示名默认项目目录 basename 或短线程 ID，不从提示词猜任务名。RPC 接收到正文必须丢弃，不进状态、日志、fixture 或报告。

| 证据 | 状态 | 输出 |
|---|---|---|
| UserPromptSubmit / 明确 task_started 或 turn/started | running | working，安静；不显示完成百分比 |
| PermissionRequest / waitingOnApproval | waiting_approval | curious，“需要回到 Codex 确认。”；不作审批 |
| 明确 waitingOnUserInput | waiting_input | curious，“需要补充信息。” |
| 观察到后续明确执行事件 | running | 解除原等待状态 |
| 对应 turn 的明确完成 / Stop | turn_completed | happy，“本轮已结束，请查看结果。” |
| 明确 turn failed、不可恢复终态 | failed | confused，“本轮失败，请查看 Codex。” |
| Interrupt / 明确 aborted | interrupted | 中性短提示；不冒充失败或成功 |
| 工具失败但可重试 | 保持本轮状态 | 不误报整轮失败 |
| 网络失败、未知事件、缺少终态、过期 | unknown/stale | 中性状态；不擅自推断完成 |

SessionStart 本身不意味着正在执行；SessionEnd 不等于一轮成功；SubagentStop 不得结束父任务。Stop 可能缺少 turn_id，必须使用来源会话内的轮次边界生成稳定代际；不得跨重启重复播报。PermissionRequest 可能很快解除，优先消费最新有效状态，已解除的提醒丢弃。

### 4.2 去重、恢复与时效

- 去重键至少包含 source_instance/thread/turn/event；有官方 event_id 时优先使用。重复、乱序、迟到旧轮次不得覆盖新轮次。
- 首次启用/重启/重新连接只建立历史基线，不补播历史终态。启用后产生的短任务，即使开始和结束处于同一次轮询，也可提醒一次结束。
- JSONL 使用增量偏移、残行缓冲和截断/替换检测；有文件数/行长/单轮读取预算，禁止每秒重扫所有历史。忽略正文，只识别白名单结构类型。未知 schema 标为不支持。
- 任务状态显示 last_seen。没有心跳的 hook/日志源，连续 120 秒无可验证证据转过期；明确标明可能仍在工作，不能用定时器结束任务。
- 同一任务保持关注直到明确终态/过期/用户改选；其他任务待确认以列表/角标提示并按优先级调度，不频繁切换关注项。
- 提醒排队有效期 90 秒；一般桌面气泡约 12 秒。v0.18.2 起“本轮已结束”桌面气泡默认保留 5 分钟，点击气泡可提前关闭；其占用通知队列的时间仍为 12 秒，后续有效提醒可覆盖它。本机历史最多 50 条、不存正文。断线恢复先基线再处理新事件。

## 5. 额度规则

1. 初始化 RPC 握手后调用 account/rateLimits/read，只允许必要只读方法；专用子进程启动隐藏窗口、超时可取消、退出仅清理自身进程。不修改用户配置、不读取 auth.json、不自动登录。
2. 优先 rateLimitsByLimitId，缺失时兼容 rateLimits；桶按实际 limit ID/name 展示。不得把多个不同桶的 primary/secondary 拼成一对。
3. usedPercent 是已用，remainingPercent=clamp(100-usedPercent,0,100)。null、缺字段、非法非有限数不能变成 0；窗口名称按实际 windowDurationMins 形成，无时长则“窗口 1/2”。
4. resetsAt 为秒；显示本地时间与剩余时间。到达重置时间后标记“等待刷新确认”，不得自行填 100%。
5. 新鲜度与连接状态分开；成功样本超过 5 分钟或重置时间已过，数值带过期标记，禁止低额语音。失败时可展示上次数据和采样时间，不能伪装实时。
6. API Key、未登录、不支持额度、认证失败、无窗口与网络错误分别可解释。不要将这些情况当额度耗尽。
7. 低额通知按来源/桶/窗口/重置周期去重；仅从高于阈值到低于阈值，或启用后首次新鲜低额时提醒一次。升至阈值+5 后重新武装；未知/过期不重置去重。
8. 任务与额度无法核实同一账号时，必须保留“当前监测账号额度”而非“该任务额度”。更换来源/账号边界要清缓存并重新基线，不混旧数据。

## 6. 共享输出调度

Controller 提供进程级自动输出协调；造价和 Codex 统一经过这层。不得直接用 play_character 模拟自动提示，因为它设置人工优先窗口。保持已有 auto_available、15 秒人工优先和设备音频忙判断。

优先级：人工/语音/设备音频 > 需要确认或输入 > 失败 > 本轮结束 > 额度低 > 普通工作姿态。同优先级 FIFO，优先任务未输出前重查时效/代际/最新状态。不得因独立 monitor 同时检查可用而重复覆盖桌面或声音；用共享锁/租约并在锁内重查条件。低优先级工作姿态不得覆盖其他来源有效提醒。

关闭 Codex、停止全部、退出分别使 Codex generation 失效、清队列、取消轮询/额度子进程和自身在播音频，拒绝迟到回调；停止监测不调用 Codex interrupt/stop。关闭 Codex 不关闭造价哨兵。Windows 阻塞声音工作线程的取消不等于已静音，必须验证实际停止机制。

Watch 只走原 Robot/单 BLE 连接/写锁；输出满足 24 字与 72 UTF-8 字节限制。不引入额度固件 UI、不重绑。交付记录分为 queued/displayed_to_client/sent/failed/offline 等，不把发送成功称用户看见或听见。

## 7. 接口与文件职责

建议新增模块：codex_source.py（RPC、hooks/JSONL 读适配）、codex_monitor.py（状态/额度/生命周期）、notification_coordinator.py（共享输出）；可按实际代码合理拆分，避免无意义框架化。

| 位置 | 职责 |
|---|---|
| companion/app.py | 单实例生命周期，GET/PUT /api/codex/sentinel、POST /api/codex/quota/refresh，复用 Host/Origin/owner 约束 |
| companion/control.py | 自动状态协调、desktop_state 的 codex 摘要、stop-all |
| companion/task_monitor.py | 造价提醒接共享协调，保留现有业务行为与声音缓存 |
| tools/codex_sentinel_hook.py（建议） | 白名单事件转发，快速失败/关闭无操作；输出为空、退出 0，不改变 Codex 流程 |
| ui/console.html + static/app.js/CSS | 独立入口、状态/列表/设置/额度及配置说明；必须 build:ui |
| gork-desktop/main.js、avatar.* | 白名单状态转发、细环和悬停/键盘详情；保持拖拽、缩放、主题、气泡 |
| tests | 真实协议结构的脱敏 fixture、状态/并发/停止/API/UI/环回归 |

若 hook 经 HTTP 转发，使用本机专用随机凭据，凭据保存在忽略文件且不放入 URL；严格 body 长度/字段/来源、限速，禁跨源。也可采用有界本地队列以避免额外入口。配置安装工具默认 dry-run，安装/卸载仅精确合并/删除 Gork 自己的条目并备份，保留他人 hooks。初版无需修改全局配置即可用显式启用的实验 JSONL；如需要 hook 信任，交付可审核配置后由用户在 Codex 完成信任。未信任状态必须明确。

## 8. 非功能要求与验收边界

- 增量任务采集目标 1 秒，轻载本机新事件到队列目标 <=3 秒；真实延迟须记录 source/observed/dispatch 三时刻，不把测试时钟推算当实测。
- UI 不超过原 500ms/既有轮询额外创建多个采集器；额度请求合并且有退避。重开页面/切主题不能重启采集或抢语音。
- 只读 Codex 数据、loopback 服务、无浏览器登录抓取、无私有云 API、无 raw rollout 持久化或进入 Git。
- JSONL 后备无法可靠识别等待审批时，标“该来源不提供审批状态”，不要从回答问号猜测。支持的能力与实际已接通分开显示。
- 单测、构建、隔离浏览器、真实只读采样、正式 Electron、Watch 实屏/听感分别记录；任何未测项目不能 PASS。
- 发布候选允许真实 hook/Watch 验收待人工，但必须完成全部可自主执行源码、测试、可用性探测和清晰使用步骤，不以接入能力不足为由交付静态演示。
