## 4. 执行门禁和禁止事项

- 先记录 `git status --short`、相关版本、已有进程/端口，只读检查；已有脏改动和未跟踪目录均视为用户资产。
- 不使用 `git add .`、整仓 reset/clean、覆盖未归属改动；无权把历史未跟踪代码都算本轮新增。
- 不进行常规 SHA 文件校验，不生成 SHA256SUMS。此轮不改固件，不需编译/读回/烧录。
- 页面默认许可按用户已确认偏好保留，但执行模型不得据此自行进行云端付费请求或录制用户环境音。测试使用合成数据、mock 和已授权的本机服务。
- 不自动连接/操作实体设备，不结束用户正在使用的进程。需要真机或正式重启时明确列为人工门禁；隔离端口启动测试进程并在结束后仅清理自己启动的进程。
- 如需浏览器/桌面工具，遵循对应技能；不要为测试临时关闭 Electron 安全限制或放宽同源约束。
- 不擅自开启多代理并发。同目录并发需用户明确批准且先划分责任。

## 5. 分阶段执行（顺序固定）

### M0：建立可核验基线

1. 完整读文档和相关代码，记录现有测试结果及失败项，不把旧报告数字当本轮运行。
2. 创建 `04-output/v0.9.0/实施与验收记录-【codex】.md`，写基线版本、脏树保护、范围、阶段表、逐项用例。
3. 核对声音实验模式真实枚举、会话授权路径、停止链和桌面接口；记录 PRD 与代码差异。
4. 在报告冻结：路由名称、工作台 owner 与语音 session 关系、角色状态字段、取消顺序、桌面存活判断。按 PRD 给出的最小设计实现，不扩展协议框架。
5. 按四页列出旧功能去向；不存在的功能不能标“仅迁移”。

完成标准：基线可复现、范围无隐性依赖，不需要向用户重复确认已明确的页面分类。

### M1：四页骨架和共享状态

1. 建立 hash 导航、页面容器和全局状态/停止；保留一个 API 客户端、心跳、Epoch 和音频控制器。
2. 先搬现有功能，不改变外部接口；每搬一组完成对应回归，防止后面难以定位。
3. 覆盖前进后退、刷新深链接、未知路由、窄屏、焦点导航、切页录音结束与隐藏任务提示。
4. 统一 toast/错误提示，长技术详情折叠；不得把所有卡片换容器后仍呈现同样拥挤的首页。

完成标准：旧功能均可找到，导航无重复 timer、重复 DOM 绑定或第二个 BLE 会话。

### M2：对话与设置形成完整流程

1. 对话页实现转写可编辑、朗读/AI 对话区分、发送、停止、清空会话。
2. AI 未配置用明确禁用状态；已配置状态用 mock 验证完整答复路径，不能实际冒用用户云凭据。
3. 将路由、音色、语速、应用保存与固定文本试听合组；处理旧服务/空能力/加载失败/未保存状态。
4. 保留旧 localStorage 设置、false 优先、隐私撤销立即生效以及试听不改输入/上下文。
5. 服务管理保留已有自动托管和复用策略；不实现强制杀进程“重启”按钮。
6. 按补充 18 提取无 Gork 页面依赖的 Recorder/Player 模块，统一所有电脑播放入口的停止/互斥；独立 VoiceClient 不反向依赖产品模块。

完成标准：本地流程可运行，声音设置无需跨页找另一个保存按钮，所有失败有恢复路径。

### M3：工作台控制权与角色控制

1. 先补控制权及并发测试，再将设备授权与 voice.session 解耦；不得为解耦删除 owner 验证。
2. 增加严格角色目录和表达/气泡接口，复用 BLE 工具；实施目标支持矩阵。
3. 渲染器支持一次播放回 idle、明确循环、同名手动重播；自动状态轮询不重启当前时间轴。
4. 23 个来源表情网页/桌面支持；happy-work Watch 专属并且不可冒充桌面完整实现。
5. 实施 8 秒气泡、长度/编码限制、旧计时器失效、纯文本安全显示、分目标结果。
6. 设备离线/语音离线/两窗口接管/忙状态覆盖；无论 UI 禁用与否，后端必须同样拦截。
7. 增加仅释放语音会话的操作；角色/设备 owner 保留。第二程序不能偷偷接管语音，显式接管后旧端不能自动抢回。

完成标准：语音服务不可用时角色预览与工作台设备控制仍可用（设备操作使用模拟验证），无未授权写入和旧状态重放。

### M4：StopWatch 页与桌面集成

1. 整理连接、声音、音量、实验和诊断区，不增加固件未提供的功能。
2. 电脑试听和设备播放互斥协调；音量提交合并、真实回执、失败状态不假成功。
3. 实验任务切页仍有全局可取消提示；全局停止可打断持锁传输，不等待整段结束。
4. 桌面订阅完整角色状态，增加存活/接收证据；只在存在桌面桥接时开放窗口设置。
5. 保留拖动、托盘、单实例、位置恢复、退出时仅关闭自有服务、点击小人打开控制台。
6. 检查气泡不裁切、隐藏不自动弹出、同源角色不失真。

完成标准：网页和 Electron 共用一份业务状态；不因为新增角色窗口再创建语音或 BLE 控制链。

### M5：回归、交付与版本收口

1. 运行本仓库 Python、Node、目录一致性检查；补齐下表用例。
2. 隔离测试实例做四页真实浏览器验证，保存关键截图、控制台异常与网络失败检查结果。
3. 可用时检查真实 Electron 的角色/气泡/托盘/单实例。真实麦克风、设备动作和付费请求保留人工门禁。
4. 电脑端实际版本更新为 v0.9.0-dev；统一健康接口、Electron package 及相关标识，不能碰固件版本。
5. 更新 README、AGENTS、当前计划、两个电脑端 README、CHANGELOG 与验收报告；CHANGELOG 保留 5 版，超出移历史归档。
6. 第二位版本变更的本地 Git 规则仅应用于明确归属且已检查的路径；脏树归属不清时如实说明，不强行混合提交。未经本次授权不 push。
7. 正式运行旧进程时，只报告源码已完成及生效步骤；取得用户重启授权后再替换正在使用的实例。不能因测试实例通过宣称正式桌面已更新。
8. 按补充 18 交付独立 HTTP 示例及接入说明，执行 V01–V08；使用隔离服务和合成非私人数据验证“不启动 Gork 也能调用 ASR/TTS”，不能只以 import 成功代替复用验收。
