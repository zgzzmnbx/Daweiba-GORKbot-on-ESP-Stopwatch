# v0.17.1 芊悦播报语音库

## 范围

Gork 任务哨兵沿用 PRD 28 的业务节点与表情。18 条固定短句统一登记，使用现有语音服务支持的 `qwen3-tts-flash` / `Cherry`（芊悦）生成一次并保存为本机 WAV。正常提醒只读取本机文件；没有缓存时明确记录 `cache_missing`，不静默换声或请求云端。

## 控制面板

角色页“小人播报语音库”逐条显示分组、短句与缓存状态。可试听缓存、生成缺失项、重新生成单条；试听仅在电脑播放。生成操作要求当前语音会话、云端 TTS 路由和文字上传许可均有效，不接管其他会话，不更改语音路由。缓存文件放在项目忽略目录 `Codex-Temp/sentinel-speech/cherry-qwen3-tts-flash-v1/`，用音色、模型、文字区分文件；不保存密钥或业务原文。

## 验收

- 18 条固定短句均有合法的单声道 PCM16 WAV，时长与大小满足现有 Watch 音频入口。
- 已缓存短句重复生成时不调用云端；单条更新才重新请求。提醒路径不合成、不上传。
- 没有云端 TTS 或文字上传许可时生成接口拒绝；试听缓存不调用云端。
- 正式桌面客户端重启后验证界面和真实任务；Watch 表情、文字和实际可闻单独验收，不以格式或回执代替听验。
