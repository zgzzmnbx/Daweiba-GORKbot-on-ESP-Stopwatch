## 1. 目标和完成定义

在用户的 vivo 手机交付可安装的独立 Gork APK：不依赖电脑启动，直接以加密 BLE 控制当前 StopWatch；分阶段补齐手机语音、AI 回答和 Watch 朗读。保留桌面现有运行能力，Android、桌面、固件分版本管理。

v0.1.0 完成基础控制；v0.2.0 完成首个手机语音控制闭环；v0.3.0 完成可选悬浮伴侣与长稳优化。只生成 UI 或构建 APK 不能关闭真机、可闻、恢复与数据保留任务。

规划轮只制定文档。用户于 2026-09-27 要求开始执行后，已从 T00 开始实施；任何既有电脑配置、其他项目、全局配置、设备固件、手机配对状态仍不得因阅读本任务书自动改变。

## 5. 任务包与依赖

所有任务初始状态均为 NOT_STARTED。每个任务报告包含变更、命令、实际结果、失败原因、未测项和下一步；不得用空表充当验收。

### T00 设备与开发基线（G0 后）

- 只读确认手机型号、Android API、OriginOS、WebView 版本、ABI、蓝牙能力和已装语音引擎；ADB 未连时如实记录，不猜测。
- 核对 JDK/SDK/构建工具可复用性；建立标准 Gradle 工程和本地构建说明，冻结包名、min/target/compile SDK、签名管理方案。
- 给出绑定迁移和恢复清单，确认手机主控是否符合使用习惯。对尚无手机实测的关键项分列 BLOCKED。
- 输出：`开发基线与环境记录-【codex】.md`、工程 README、可重复构建命令。
- 退出条件：工程可构建最小壳、设备与未确定项完整记录；不得声称 BLE 已完成。

### T01 协议与平台接口（依赖 T00）

- 导出表情/文字/声音/音频 UUID、字节序、包头、有效值、超时和错误码；完整读取 `tools/stopwatch_audio.py` 与 `tools/stopwatch_opus.py`，建立跨语言 golden vectors。
- 冻结桥 v1 Schema、capabilities、state snapshot、generation、requestId、eventSeq 及任务终态。确认页面副作用只有原生协调器拥有。
- 提取桌面 HTTP/Electron 与 Android NativeBridge 的最小接口；既有桌面默认行为保持，避免整份 app.js 分叉后各自维护。
- 输出：协议表、桥契约、模拟适配器和双平台契约测试。
- 退出条件：合法/非法包、字节序、旧通知、未知方法、取消、过期代际测试通过；旧 BLE 无 request_id 的限制写进接口说明。

### T02 APK 内移动页面（依赖 T01）

- 实现四标签、顶部角色、统一输入和目标选择；主题、形象、草稿、设置持久化。
- 用 WebViewAssetLoader 加载本地资源，限定桥 origin/main frame、白名单和消息大小；禁止外页获得桥、模型 HTML 注入、任意网络代理。
- 构建时生成资产并检查来源一致性；手机无法使用的 Electron/电脑服务项按能力隐藏或明确不可用。
- 输出：离线可启动 APK 候选、移动布局截图、共享资源导出脚本。
- 退出条件：A01–A05、A18 对应离线/界面部分通过；不能因模拟按钮可点就记录设备功能 PASS。

### T03 原生 BLE 与主控迁移（依赖 T01；真机部分需 G1）

- 实现运行时权限、扫描、目标选择、系统配对、服务发现、CCCD、MTU 和 Ready 状态机。
- 单 BluetoothGatt、原生回调队列、应用任务锁；串行命令回执、连接 epoch、超时关闭连接、手动断开终止自动重连。
- 实现“已绑定其他控制端”的说明与人工迁移引导；不自动清绑定，不反射调用隐藏配对接口。
- 在获准后测试手机绑定及电脑恢复；恢复后需要重新迁回手机进行后续用例时确认现有授权覆盖范围。
- 输出：状态机测试、扫描/连接失败映射、真实 GATT 与换绑/恢复记录。
- 退出条件：A06–A09、A20；权限拒绝、旧回执、陌生端行为不能靠模拟替代真实安全验收。

### T04 基础控制版本 v0.1.0（依赖 T02、T03）

- 接通表情、气泡、清屏、六种短音、音量和全局停止；手机/Watch/两端分别显示结果。
- 处理 Watch 设置页 BUSY、中文边界、emoji、重复点击、断连中提交、停止后旧回执。
- 首次输出中等音量，保留设备音量；不得增加固定大倍数增益。系统 TTS 探测作为可选能力，失败不阻塞基础 BLE。
- 输出：v0.1.0 APK、安装/升级文档、基础验收报告。
- 退出条件：A01–A11、A18–A20 的本版项通过；未连真机时只能发候选包。

### T05 手机音频与 Provider（依赖 T01、T04；联网需 G2）

- 原生录音、播放、音频焦点及来电处理；前台按键开始，松开/停止/后台切换结束录音。
- 实机探测本地中文 ASR/TTS；区分仅 speak、可合成文件、需要联网、缺语言包、不支持五种情况。
- 接通一个真实 ASR、一个可输出完整音频的中文 TTS、一个 AI 文字 Provider；可配置 HTTPS、超时、取消、限长与错误；原生安全存储凭据。
- 三项上传许可独立，撤销即停；无配置、断网、额度不足保留文字输入，绝不静默改 Provider 或改上传范围。
- 输出：Provider 能力报告、真实输入输出样例的脱敏元数据、焦点/取消测试。
- 退出条件：A12–A14、A17；音频数据仅保存在私有临时目录，报告不含用户私密录音和 Key。

### T06 Watch Opus/PCM 朗读（依赖 T03、T05）

- 先用固定完整 WAV 验证 PCM；再实现可与现有固件互通的 Opus 包格式及预跳过采样数，不能直接发送 Ogg 文件。
- 优先评估可复用的 Android 编码能力；若平台编码输出无法可靠满足固件协议，锁定 libopus/NDK 构建路线并记录 ABI、版本、许可及构建命令。不得以“手机支持 Opus 播放”推断具备兼容编码。
- 实现格式转换、长度限制、能力协商、MTU/包长、3 包应用窗口、ACK 进度、超时/CANCEL 和文件清理。
- 保持 COMMIT → 文字 → PLAY 同轮锁和停止优先；大于 10 秒明确拒绝/提示缩短，绝不静默裁音。
- 输出：跨语言音频向量、同 WAV Opus/PCM 对照、完整句用户听验记录。
- 退出条件：A15–A17；只收到 PLAYED 不算听验通过。

### T07 生命周期与 v0.2.0 收口（依赖 T04–T06）

- 有通知的 connectedDevice 前台服务、用户开启/关闭保持连接、后台条件检查和有界重试；息屏暂停不需要的 WebView 渲染。
- 进程重建恢复偏好/草稿；未完任务转为中断，禁止重播；系统强停后等待用户重新打开。
- 做 30 分钟链路、息屏、真实离开/返回、网络切换、权限撤销；收集设备设置与电量条件，不代用户擅改全局省电设置。
- 输出：v0.2.0 APK、完整用例矩阵、性能/听感记录、未决限制。
- 退出条件：本版全部必需项通过；离线语音若未实现，应明确“云语音可用，本地语音不支持”，不影响已确认的云路线交付。

### T08 悬浮伴侣 v0.3.0（依赖 T07，按确认的后续优先级执行）

- 实现可选悬浮小人、拖动、收起、关闭和气泡；独立核对 overlay 权限及支撑服务的适用类型/启动限制。
- 拒绝/撤销权限立即退出悬浮，主 App 保持可用；锁屏隐藏正文，系统拦截触摸或不允许显示时明确降级。
- 做至少 2 小时前台/后台混合使用记录、4 小时低交互耗电对照；记录掉线、温度、电量，不预设无证据的续航保证。
- 输出：v0.3.0 APK、悬浮/隐私/耗电报告。
- 退出条件：A21–A22；不包含多绑定固件、远程网关或造价服务部署。

### T09 每版打包、归档与项目记录（依赖对应版本任务）

- 构建前归档上一 APK，文件名带 versionCode 与 versionName；升级保持 applicationId 与签名，私有数据不丢失。
- 锁定构建依赖、保留签名校验结果、第三方来源、源码提交/脏状态、实际测试范围；签名材料、凭据、私人音频不入 Git。

- 输出：APK、版本清单、安装升级/回退说明、验收矩阵；G4 后才标注对应版本完成。

## 7. 验证执行原则

1. 协议纯单元测试先覆盖坏包、字节序、ACK/epoch、取消和超时，不写与实现逐行对应的空洞测试。
2. 宿主集成测试覆盖桥权限、生命周期、GATT 队列及 Provider 失败；模拟器不能代替 vivo 蓝牙、OriginOS 后台和声音验收。
3. 构建使用模块 Gradle Wrapper，具体 task 以生成工程为准；记录真实命令与退出码。APK 签名工具检查通过后再安装，不靠文件名推断版本。
4. 共享代码改动运行现有针对性回归，并执行 `npm run build:ui` 及资产分发检查；如果只改 Android 模块，不为凑数量构建/刷写固件。
5. 真实设备用例按受控顺序：中等音量→完整短句→停止→断连恢复→息屏长稳。不要截取半句作为听感样本。
