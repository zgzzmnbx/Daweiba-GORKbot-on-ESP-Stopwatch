# Mantine 控制台与经典主题 PRD v1.0.0

日期：2026-09-26。用户已授权全面重绘并保留旧主题按钮；电脑端版本 v0.15.0-dev。

## 范围与视觉

保留左侧常驻动态 Gork、右侧对话/造价助手/角色/StopWatch/设置/运行日志六个标签页。默认 Mantine 主题，矿物灰绿底、白色工作面、绿色主操作、薄边界、36px 常规控件和 8/12/16/24px 间距。输入区仅一层边框；角色形象设置继续归入角色页，快捷表情保留左侧。日志可展开独立标签阅读。桌面浮窗、气泡和 Watch 固件外观不属本次重绘。

## 架构

使用固定版本 @mantine/core 9.6.2、@mantine/hooks 9.6.2、React/ReactDOM 19.2.4。为保留现有经过回归的原生 DOM 控制器，构建时把 `ui/console.html` 映射为真实 Mantine Button、NativeSelect、Textarea、Switch、Checkbox、Paper、Title、Badge、Input 并预渲染；滑块使用原生 range 保留设备大小/音量事件语义，标签导航与 details 沿用现有交互。无 React 运行时、无 hydration，不另外复制会话/停止/BLE 状态机。模板内各业务 ID 必须唯一，原生控件类型保持兼容。

生成 `static/index.html`、`static/mantine/vendor.css`、`static/mantine/components.css`；设计布局在 `static/modern.css`，经典兼容层在 `static/classic-bridge.css`。所有 Mantine 行内样式及主题变量构建时外置，不改变后端 CSP。运行可离线读取静态资源，npm 只在开发构建时使用。

## 主题切换

右上角按钮随当前主题显示「经典主题」或「Mantine 主题」。仅切换 stylesheet media 和根属性；本机 `gork.console-theme` 记忆，非法值/存储不可用时默认 Mantine，仍允许当次切换。保留原 `style.css` 与米白/橄榄绿视觉。切换保留 DOM 身份、草稿、对话记录、表单值、展开状态、当前标签、禁用状态及监听器；不得发起 fetch、IPC、重载或重新挂载头像。

## 验收

- 两种主题下六页可访问，功能 ID 无丢失/重复，原生控件类型一致。
- 1180×820、800×540、390×540 窗口内无整体横纵溢出，对话提交与主题按钮可达；窄屏伙伴区内部滚动，内容不互相覆盖。
- 实际生成 DOM 集成测试加载原 app 控制器；模拟接口验证输入、开关、路由、隐私撤销、角色气泡及主题切换无重复请求。
- 保留原 74 项桌面/页面/形象测试；新增 4 项主题/生成界面回归。构建检查与 npm audit 通过。
- 隔离 8879 禁止自动 BLE/语音连接，仅检查界面。正式 Electron、真实云语音和 Watch 需另外实测，不将模拟或离线页面当成硬件验收。
