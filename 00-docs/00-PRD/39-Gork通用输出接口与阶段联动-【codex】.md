# Gork通用输出接口与阶段联动 PRD39

版本：PC v0.20.28-dev / 协议1.0；2026-10-08。

用户确认边界已由grilling完成，不继续重复询问。外部程序只发输出；本机来源首次登记/启用、输出端与优先级授权、当前用户音色/声音端、通知与状态分开。普通排队，同任务新阶段替换未开始的旧阶段，重要失败视觉可覆盖但不默认中断已开始声音。状态30秒租约/10秒心跳，普通TTL30秒、完成/失败90秒；取消与重启不补播。

## 模块与所有权

- Gork：来源registry、令牌hash、权限；严格Notification Schema；持久回执/序列/取消tombstone；共用通知通道、双端视觉、当前TTS/缓存；通知哨兵界面。
- Astra：业务事件和实际attempt/金额语义；阶段表情/文字/声音/时长映射设置；持久outbox/sequence、状态心跳、取消和结果收集。指定线程01a11685-a05b-7dc1-b41c-684b63835c7c授权配合。
- Astra 设置提供“调试”页，手动选择并发送各阶段，复用已保存映射与同一 SDK/outbox；展示请求摘要、接收回执、逐端结果并可取消。测试使用独立 task_id/attempt 和明确调试标识，不发布真实业务事件、不执行匹配或审查，模拟金额不写入真实金额。
- Watch：复用原有网络和音频协议，不改固件；不增加第二BLE客户端。

## 完成口径

1. 主动调用不能接管人owner或录音；来源只能查/取消自己的通知，注册/权限调整为工作台owner操作。
2. 精确请求重复不二次输出；同ID不同内容409；过期/旧sequence/取消晚到拒绝；队列有界；重启旧在途interrupted。
3. 人工语音/表情优先；当前语音不被普通新阶段截断；状态心跳不重播或复活。显示双端和单声音端分离，权限修改取消对应输出。
4. 界面三主题/四宽度无控件重叠/越界，可滚动到配置与最近回执；不保存或记录令牌。
5. 完整中文快速接入文档、Schema和SDK可用；Astra用实际producer和隔离HTTP服务验证，模拟输出明确标识。
6. 正式Gork仍27供用户金额测试；候选两端正式启用和真实阶段/桌面Watch听感不冒充自动回归通过。本轮无固件、网络、云和业务测试触发，性能/长稳延期。
